Incidents in Detail
#1 Topic Ambiguity — Unnecessary Clarification Round-Trip MEDIUM
What happened
User asked for a "technical deep dive" without naming the subject. Agent correctly asked for clarification — adding one full round-trip before any work could start.
Root cause in repo
No CLAUDE.md at the project root, no README.md, no package.json description field visible at top level. The agent had no signal that "this codebase = claude-code-rebuilt".
#2 Two-Phase Explore — Wasted Quick Scan MEDIUM
What happened
Agent ran a quick Explore pass (57s, 37K tokens) to produce a slide outline for scope confirmation. The user responded "comprehensive HTML overview" — meaning the quick scan output was used only to generate a list the user largely ignored.
What should have happened
A single deep Explore pass with file output, then write the HTML. The quick-scan + confirm gate added ~90 seconds and a wasted agent invocation. An ARCHITECTURE.md at root would have let the agent skip the orientation scan entirely.
#3 Explore Agent Can't Write — 80K Tokens Dumped Into Context HIGH
What happened
The Explore subagent type has no Write tool. When asked to save findings to a file, it said "Since I cannot write files, I'll provide the findings directly" — dumping ~80K tokens of analysis inline into the main conversation context. This directly violates the CLAUDE.md rule: "When any tool or agent call returns >5,000 tokens → write to a temp .md file, show only a summary."
Root cause
Wrong agent type selected. Explore is read-only by design. For research tasks that need file output, the correct choice is the general-purpose agent, which has Read + Write + Bash access.
Impact
Every subsequent turn in the session runs with a bloated context window, degrading response quality and increasing latency. The HTML slide generation itself had to work from a noisy inline dump rather than a clean structured file.
#4 Glob Search Returned node_modules Noise LOW
What happened
Glob("*.html") ran against the repo root and returned 100+ HTML files from node_modules/ subdirectories. The agent had to mentally filter noise to confirm no existing output file.
Fix
A .gitignore / .agentignore scoping file, or a more specific Glob path (path: "/Users/.../cc" with no recursive descent into node_modules). A .claudeignore would have blocked the noise entirely.
